# Чему учить сеть узнавания

Робот видит то, что ему назвали. Сеть DOSOD открытословарная: набор классов
задаётся списком слов, а не зашит в веса. Восемьдесят классов COCO, с которыми
она приезжает, — комплектация, и нам она не годится дважды.

**Не хватает главного.** В COCO нет шкафа, двери, батареи, тумбочки, полки,
стиральной машины — половины того, из чего состоит жильё. Обход это честно
признавал в своей же шапке; признать — не то же, что исправить.

**Лишнее мешает.** Жираф, зебра, сёрфборд, светофор, паркомат в квартире не
встретятся никогда, но сеть обязана каждый кадр решать, не они ли перед ней.
Каждый невозможный класс — лишний шанс ошибиться, и ошибки эти мы видели:
«унитаз — 2, кровать — 2» посреди комнаты.

**Цена по скорости — ноль.** Буква D в DOSOD означает decoupled: текстовая
ветка отделена от картиночной и считается заранее, на ПК. На роботе от размера
словаря меняется только последнее перемножение с матрицей классов — восемьдесят
классов там или сто, разницы нет и в миллисекунду. Платим разовым прогоном на
ПК, а не временем на каждом кадре.

## Где лежит список

`voice/robot_voice/vocabulary.py` — единственное место. Оттуда же берутся
русские имена (`things.ПО_РУССКИ`), рост для запасного измерения дальности
(`landmarks.РОСТ_ПРЕДМЕТА`) и признак подвижности (`landmarks.НЕ_МЕБЕЛЬ`).

Раньше это были три таблицы в двух файлах, обязанные совпадать, и ничто их к
этому не принуждало. Цена рассогласования тихая: класс, забытый в таблице
роста, узнаётся, называется по-русски и **не попадает на карту** — потому что
`мебель()` смотрит именно на рост. Снаружи это «робот видит стол и не
запоминает его», а причина в третьем файле. Проверка в `selftest` теперь
следит, чтобы разъехаться было негде.

Добавить класс — одна строка в одном месте:

```python
_в("humidifier", "увлажнитель", рост=0.40, откуда="наш"),
```

Английское имя — для сети (текстовый кодировщик у DOSOD английский, CLIP;
«шкаф» он не знает, `wardrobe` знает). Русские — для человека.

## Порядок слов — это номера классов

Сеть отдаёт **номер**, а не слово. Список, из которого считались эмбеддинги, и
список, по которому робот эти номера расшифровывает, обязаны совпадать строка
в строку. Разъехавшись на одну, они превратят стул в холодильник молча, без
единой ошибки в журнале.

Поэтому json генерируется из того же модуля, а не пишется руками:

```bash
python3 scripts/make_vocabulary.py --показать      # посмотреть, что выйдет
python3 scripts/make_vocabulary.py --out vocabulary_kuzya.json
```

## Переучивание: пять шагов

Шаги 2–4 идут на ПК с torch и CLIP, шаг 5 — в докере тулчейна Horizon.
Прогон разовый; на роботе после него меняется только файл модели.

Репозиторий: <https://github.com/D-Robotics-AI-Lab/DOSOD>

**1. Список слов** — наш скрипт, см. выше.

**2. Эмбеддинги слов.** Тянет `clip-vit-base-patch32`.

```bash
python3 tools/generate_text_prompts_dosod.py \
    configs/dosod/dosod_mlp3x_l_100e_1x8gpus_obj365v1_goldg_train_lvis_minival.py \
    DOSOD/dosod_mlp3x_l.pth \
    --text vocabulary_kuzya.json \
    --device cpu \
    --out-dir ./work_dir
```

**3. Впечь их в веса.**

```bash
python3 tools/reparameterize_dosod.py \
    --model DOSOD/dosod_mlp3x_l.pth \
    --out-dir ./work_dir \
    --text-embed ./work_dir/offline_vocabulary_dosod_mlp3x_l.npy
```

**4. В ONNX.**

```bash
python3 deploy/export_onnx.py \
    configs/dosod/rep_dosod_mlp3x_l_100e_1x8gpus_obj365v1_goldg_train_lvis_minival.py \
    ./work_dir/dosod_mlp3x_l_rep.pth \
    --without-nms --device cpu --work-dir ./work_dir
```

**5. В `.bin` для BPU** — тулчейн X5 (OpenExplorer, docker), конфиги
`*_d-robotics.py`. Готовый `.bin` кладётся туда же, откуда его берёт узел:
`~/tros_ws/config/` (см. `scripts/setup_things.sh`).

## Пока модель не переучена

Ничего не ломается. Новые классы сеть просто не отдаёт — робот их не увидит,
но и не споткнётся. Старые восемьдесят классов COCO по-прежнему называются
по-русски: они остались в словаре как `УЛИЧНОЕ`, вне списка для сети. Это
нарочно — «bicycle» вслух вместо «велосипед» выглядело бы поломкой.

Проверить, что робот получил новую модель, можно по описи: если в ней
появились дверь, батарея или шкаф — переучивание доехало.
