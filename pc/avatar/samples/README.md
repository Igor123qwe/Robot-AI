# Готовые модели Live2D (samples/)

Три официальные бесплатные модели от самой Live2D Inc. — чтобы после
`git pull` можно было включить персонажа без ручной установки. Своя модель
(купленная, заказанная) кладётся, как и раньше, в `pc/avatar/model/` — той
папки в git нет — и путь к ней пишется в `config.local.json`.

| Папка | Кто | Формат | Откуда |
|---|---|---|---|
| `shizuku/` | **Shizuku** — фирменный персонаж Live2D, самый узнаваемый: вокруг неё выросли все «настольные девочки» (kanban musume), десять лет как эталон «живой» модели. Три idle-движения, tap/flick/shake, физика волос и одежды, 4 выражения. | Cubism 2.1 (`shizuku.model.json`, `.moc`) | официальный образец Cubism 2 SDK; взят из npm-пакета `live2d-widget-model-shizuku` (набор моделей проекта live2d-widget), звуки к движениям выброшены |
| `mao/` | **Mao** (Niziiro Mao) — образец Cubism 4: лисьи уши, богатая физика (хвост, уши, волосы), 6 движений на «тап», 8 выражений. Рот у неё — `ParamA`, не `ParamMouthOpenY`; страница берёт это сама из группы LipSync модели. | Cubism 4 (`Mao.model3.json`, `.moc3`) | репозиторий Live2D `Live2D/CubismUnityComponents`, `Assets/Live2D/Cubism/Samples/Models/Mao`; файлы Unity (`.asset`, `.anim`, `.meta`) выброшены |
| `mark/` | **Mark** — образец Cubism 4, парень в футболке. 6 движений (idle, tap × 3, flick вверх/вниз), физика волос. Руки — по одному параметру на каждую (`ParamArmL`/`ParamArmR`), без составных суставов, как у Mao. | Cubism 4 (`mark_free_t04.model3.json`, `.moc3`) | официальный бесплатный образец Cubism SDK «Mark-kun»; исходные `.cmo3`/`.can3`/фон выброшены, оставлен только `runtime/` (набор для встраивания) |

## Переключить

`pc/avatar/config.json` нарочно держит модель пустой по умолчанию — без
своей настройки ПК персонажа с готовым образцом не показывает вовсе, робот
рисует домовёнка Кузю сам (см. `pc/avatar/README.md`, «По умолчанию —
домовёнок»). Включить любой образец — строкой в `pc/avatar/config.local.json`
(git его не видит):

```json
{ "модель": "samples/mark/mark_free_t04.model3.json" }
```

Руки у Марка — отдельная строка, без неё жестикулирует только голова и
корпус:

```json
{ "модель": "samples/mark/mark_free_t04.model3.json",
  "параметры": { "рука_л": "ParamArmL", "рука_п": "ParamArmR", "рука_размах": 30 } }
```

Другие образцы — так же, просто другим путём (`samples/mao/Mao.model3.json`,
`samples/shizuku/shizuku.model.json`). Если в `config.local.json` уже вписан
свой путь (например, к модели из `model/`, не в git) — он сильнее общего:
смени его или убери строку `"модель"` — тогда снова возьмётся домовёнок.

## Старый формат — нужен интернет на другое ядро

Cubism 2 (`.model.json`) рисуется другим ядром, `live2d.min.js`; Live2D
его больше не раздаёт, страница берёт его с зеркала на jsDelivr, на которое
ссылается сама библиотека pixi-live2d-display. Без интернета на ПК ни одна
модель не загрузится и так (pixi.js и мост тоже с CDN) — это не новое
ограничение, но зеркало — чужое: если оно пропадёт, страница честно
скажет «не загрузился …live2d.min.js», и тогда — переключиться на Mao.

для раздачи сами по себе; перепродавать их или выдавать за свои нельзя.
