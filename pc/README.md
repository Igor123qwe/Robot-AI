# Мозг на домашнем ПК

У RDK X5 нет видеокарты и не будет. Языковую модель он не потянет вовсе, а
Whisper тянет через силу: самую лёгкую версию и втрое медленнее звука,
половину слов перевирая. Дома при этом стоит компьютер с видеокартой,
включённый ровно тогда, когда с роботом разговаривают.

Поэтому у робота уши, рот и колёса, а тяжёлое считает ПК. Так же устроены
Алиса и Google — разница лишь в том, что их «компьютер» стоит в чужом
дата-центре.

Робот при этом не становится заложником: ПК выключен — распознаёт сам,
разговаривает через облако. Медленнее и за деньги, но работает.

## Что это даёт

| | на роботе | на ПК |
|---|---|---|
| распознать фразу в 2 секунды | 3.7 с, модель `base` | ~0.3 с, модель `small` и крупнее |
| ответить | 3–10 с, платно | 1–2 с, бесплатно |

## Установка

Нужны две вещи: **Ollama** запускает модель, `kuzya_pc.py` переводит наш
протокол в её и заодно распознаёт речь.

```
winget install --source winget Ollama.Ollama
ollama pull qwen3:4b
pip install faster-whisper
```

Модели тяжёлые — если системный диск невелик, уведите их заранее:

```
setx OLLAMA_MODELS "F:\ollama\models"
```

Переменная действует только на новые окна: закройте командную строку и
откройте заново, а Ollama выйдите из трея и запустите снова.

## Запуск

```
python kuzya_pc.py --model qwen3:4b --whisper small
```

Окно должно остаться открытым — это и есть мозг. Проверить из браузера:
`http://127.0.0.1:4000/health`.

Порт нужно открыть, иначе робот не достучится. Один раз, от администратора:

```
netsh advfirewall firewall add rule name="kuzya" dir=in action=allow protocol=TCP localport=4000
```

## Распознавание получше

По умолчанию речь разбирает Whisper — русское дообучение `large-v3-turbo`.
Рядом лежит **GigaAM** от Сбера: его учили на семистах тысячах часов русской
речи против доли русского у Whisper, и на коротких редких словах — вроде имени
робота — разница заметна.

```
git clone https://github.com/salute-developers/GigaAM.git
cd GigaAM && pip install -e .[torch]
```

Нужен ffmpeg в PATH. Дальше запускать с флагом:

```
python kuzya_pc.py --model qwen3:4b-instruct-2507-q4_K_M --stt gigaam --port 4000
```

**Чем платим.** GigaAM не отдаёт уверенность распознавания. У Whisper есть
число, по которому робот решает, можно ли по услышанному ехать: невнятная
команда отбрасывается с «расслышал слишком плохо». С GigaAM этой защиты нет —
остаются только текстовые сетки и узнавание по голосу. Поэтому он не включён
по умолчанию: выбор осознанный, а не «поставили новее — значит лучше».

Если GigaAM не поднимется, робот не оглохнет: возьмётся Whisper, о чём будет
сказано в первых строках запуска.

## Настройка робота

Узнайте адрес ПК (`ipconfig`, строка IPv4) и допишите в `~/.robot-ai.env`
одну строку:

```
ROBOT_PC_URL=http://192.168.0.X:4000
```

Она включает сразу и разговор, и распознавание. Дальше:

```
sudo systemctl restart robot-voice
```

В журнале должно появиться «распознавание на ПК» и «основной собеседник —
ПК», а после первого вопроса — «отвечал ПК» вместо адреса облака.

Проверить связь до настройки можно прямо с робота:

```
curl -s http://192.168.0.X:4000/health
```

## Выбор моделей

Сначала узнайте, сколько у вас видеопамяти на самом деле — на глаз тут
ошибаются постоянно, а от этого зависит всё:

```
nvidia-smi --query-gpu=name,memory.total --format=csv
```

Считать надо не «сколько на карте», а «сколько останется модели»: на той же
карте живёт распознавание речи. GigaAM — это несколько сотен мегабайт, Whisper
`large-v3-turbo` — около полутора гигабайт. Плюс KV-кэш под контекст. Рабочее
правило: **файл модели должен быть примерно на 2 ГБ меньше видеопамяти.**

| видеопамять | модель | файл | ответ |
|---|---|---|---|
| 6 ГБ | `qwen3.5:4b` (или `gemma4:e4b`) | ~2.5 ГБ | ~1 с |
| 8 ГБ | `qwen3.5:4b` свободно, `qwen3.5:9b` впритык | 2.5 / 5.5 ГБ | 1 с / 2–3 с |
| 12 ГБ | `qwen3.5:9b`, `gemma4:12b` | 5.5 / 7.3 ГБ | 1–2 с |
| 16 ГБ и больше | `gemma4:26b-a4b` — MoE, 4B активных | ~15.4 ГБ | 1–2 с |

MoE в последней строке не опечатка: в памяти лежат все 26 миллиардов, а на
каждый токен работают четыре. Поэтому она отвечает со скоростью маленькой
модели, а разговаривает как большая — для голосового робота это лучшая сделка
из существующих, если видеопамять позволяет.

**Русский язык.** Есть отдельная ветка, где русский родной, а не доля общего
корпуса: `GigaChat3-10B-A1.8B` от Сбера (MIT, MoE, 1.8B активных, GGUF лежит
на HuggingFace у `ai-sage`). По-русски она говорит естественнее ровесников и
при этом быстрая. Плата — вызов инструментов у неё проверен хуже: если робот
начнёт рассказывать о поездках вместо поездок, возвращайтесь на Qwen.

**Размышления.** Все свежие модели гибридные: сначала пишут ход мысли, потом
ответ. Роботу это разорительно — предел ответа у него 384 токена, и думающая
модель выбирает его целиком на рассуждения, обрывая фразу на полуслове. Мост
выключает размышления сам (`chat_template_kwargs`), но если модель их всё
равно пишет — в логе будет сказано, и лечится это нерассуждающим выпуском
модели (`-instruct`).

**Окно контекста.** Умолчание Ollama — 4096 токенов, и робот в него не
помещается: один только системный промпт со схемами инструментов это около
четырёх тысяч. За краем Ollama молча срезает начало — вместе с промптом, где
записано, кто робот такой. Поэтому мост просит окно явно, `--ctx 8192`.
Больше ставить есть смысл, только если видеопамяти с запасом: KV-кэш растёт
вместе с окном.

Модель распознавания занимает память отдельно и немного: `small` — около
гигабайта, `medium` — два. Начинать стоит со `small`: она уже заметно точнее
всего, что помещается в робота.

Если CUDA не поднимется, `kuzya_pc.py` честно скажет об этом в лог и
перейдёт на процессор. Даже так настольная машина быстрее робота.

## Ограничения, о которых стоит знать

Сервер слушает всю домашнюю сеть (`--host 0.0.0.0`) и никого не спрашивает
пароль. В домашней сети это нормально, в общежитии или коворкинге — нет:
там запускайте с `--host 127.0.0.1` и пробрасывайте порт через ssh.

Маленькая модель может сдуру вызвать движение. Запрет ехать без имени
(`ROBOT_MOTION_NEEDS_NAME=1`) от этого страхует, но пока идёт проверка
лучше держать робота на подставке.

## Проверка

```
python pc/selftest.py
```

Поднимает настоящий сервер, подставляет вместо Ollama заглушку и делает
запрос **настоящим** клиентом `anthropic` — тем же, что стоит на роботе.
Порядок событий в потоке жёсткий, и на его нарушение клиент отвечает
исключением посреди фразы; глазами это не проверить.
